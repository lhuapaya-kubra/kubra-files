# kubra-files

PM workspace for **KUBRA – Data Analytics**. Tracks work across two platforms:

- **ConfigHQ** → [Datafeed](ConfigHQ/Datafeed), [SFTP Mailbox Manager](ConfigHQ/SFTP-Mailbox-Manager), [File Transformation Service](ConfigHQ/File-Transformation-Service)
- **BizHQPlus** → [Reports](BizHQPlus/Reports)

## Structure

Each product folder has the same five subfolders:

| Folder | Contents |
|---|---|
| `specs/` | Requirements, design docs |
| `meeting-notes/` | Notes from syncs, reviews, planning |
| `jira/` | Ticket exports / summaries |
| `confluence/` | Page exports / summaries |
| `diagrams/` | Flowcharts, architecture diagrams |

## Knowledge graph

[`knowledge-graph/`](knowledge-graph) holds short hub notes for each platform and product, cross-linked with `[[wikilinks]]`. Open this repo as an Obsidian vault and use **Graph View** to browse it. Start at [`knowledge-graph/index.md`](knowledge-graph/index.md).

## Templates

[`templates/`](templates) has starter front-matter for new notes (meeting notes, Jira tickets, Confluence pages, product notes).
