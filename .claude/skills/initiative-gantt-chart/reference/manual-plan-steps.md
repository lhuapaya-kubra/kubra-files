# Manual Plan/Gantt build checklist

Fill in `{key}` (Initiative key, e.g. `KUBRA-38`) and `{name}` (Initiative name/summary) before presenting this to the user. Everything below is done by the PM directly in the Jira UI — no tool in this skill's toolset can create a Filter or an Advanced Roadmaps Plan.

## 1. Create a filter for the plan

1. Go to **Filters** in Jira → **Create filter**.
2. Use the JQL query option:
   `key = "{key}" OR issuekey in portfolioChildIssuesOf("{key}")`
3. Save the filter as **`Plan - PM - {name}`**.
4. Set **Viewers** to "My organization".
5. Set **Editors** to Group → "product-managers".
6. Save.

## 2. Create the Plan

1. Expand the left side panel in Jira → click **+** next to Plans.
2. On "Create your plan":
   - Name: **`PM - {name}`** (the `PM` prefix marks it as owned/generated by the Product Management team).
   - Access: "Open" (restrictions can be tightened later).
   - Filter: the one created above.
   - Select **Create**.
3. On "Add teams": add at least one team doing the work (more can be added later) → **Next**.
4. On "Select your default timeline view": choose **"Top-level view"** → **Next**.
5. On "Add timeline columns", add: Breakdown, Assignee, Status, Start date, Due date, Team → **Next**.
6. On "Add people to the plan": leave blank → **Next**.

## 3. Refine the Plan settings

1. Make sure the left side panel is expanded (otherwise Plan settings won't be visible).
2. Open **Plan settings** from the "…" menu beside the plan name.
3. **Details**: restrict edit access to yourself + the "product-managers" group (prevents accidental changes to your plan).
4. **Estimation and scheduling**: set "Estimate work using" to **"Story points"**.
5. **Work in your plan** → removed work items: change "Resolved work items" to **"365 days ago"**.

## 4. Configure the Gantt chart view

In the chart view:

1. **Filter** → Hierarchy → select **"Initiative to Epic"**.
2. **Group** → **None**.
3. **View Settings**:
   - Color by: **Status**
   - Sort by: **Assignee** ASC
   - Roll-ups: turn **all off**
4. Order the columns: Assignee, Status, Progress, Start date, Due date, Team.
5. Save the view.

## 5. Enhance the data

For every Epic under this Initiative, fill in as much as possible:

1. **Assignee** — a Product Manager.
2. **Start date** and **Due date** — defined by the engineering team.
3. **Team** — if missing from the dropdown, add the team to the plan first (Team tab → add Team), then assign it on the Epic.
