# Notifi support ticket — guiding questions (blank template)

Use this as the checklist when drafting. Every question gets an explicit answer — "N/A" only if it genuinely doesn't apply, never silently skipped.

## Jira fields

- **Client**: (which client/customer is affected — maps to the Customer field)
- **Severity**: (Blocker / Critical / Major / Medium / Minor / Trivial / None — maps to Priority)
- **Epic**: ANALYTICS-3204 (Notifi Reporting 2026 - Support/SD) — always

## Description

**Problem**
(What's actually broken — expected vs. actual behavior, one or two sentences.)

**Impact on client**
(Is this blocking their workflow, or cosmetic? How many reports/users affected? Is there a workaround in the meantime?)

**Source URL**
(The exact Notifi report/dashboard link where the issue was observed — not a generic homepage.)

**Screenshot**
(Embedded image URL, or: "to be attached directly in Jira UI after ticket creation.")
